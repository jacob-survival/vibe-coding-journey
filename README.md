## 📝 1주차 회고

### 배운 것

- **Cursor + AI 협업**: 자연어로 요구하면 HTML/CSS/JS를 빠르게 만들고, 수정·개선을 반복하는 흐름을 익혔다.
- **Git & GitHub**: `init` → `add` → `commit` → `push`, 충돌 시 `pull --rebase`까지 실전에서 다뤄 봤다.
- **웹 기초**: HTML 구조, CSS 레이아웃·색·폰트, JavaScript로 클릭·저장·화면 갱신을 연결하는 방법.
- **Tailwind CSS**: CDN 방식으로 빠르게 UI를 만들고, 모바일·PC 반응형을 클래스만으로 조정하는 감각.
- **localStorage**: 새로고침해도 좋아요·메뉴·가족 선택이 유지되게 하는 클라이언트 저장.
- **Vercel 배포**: GitHub 연동으로 만든 페이지를 실제 URL에 올려 가족과 공유할 수 있게 됐다.

### 만든 것

| 단계 | 결과물 |
|------|--------|
| Day 1~2 | `index.html` — 첫 인사 페이지, GitHub 저장소 생성 |
| Day 3~5 | `day3-baekfamily-draft/index.html` — **백씨네 식탁** |
| Day 6 | [Live Demo](https://vibe-coding-journey-5uzx.vercel.app/) — Vercel 배포 |

**백씨네 식탁** 주요 기능:
- 가족 선택(엄마·아빠·백지원·백승원) 후 메뉴에 좋아요
- 오늘의 인기 메뉴 · 좋아요 카운터 · 누가 좋아했는지 표시
- 메뉴 추가(이모지 그리드) · 삭제 · localStorage 저장
