## 🎯 Why Vibe Coding?

**"코드를 짜는 능력"보다 "AI에게 정확히 요구하는 능력"이 더 중요해진 시대.**

21년간 글로벌 시장에서 단련된 요구사항 정의 능력과 협상 능력을, AI라는 새로운 도구 위에서 어떻게 활용할 수 있는지 — 직접 부딪혀 가며 확인하는 여정입니다.

---

## 🧭 Learning Philosophy

- **코드를 외우지 않는다.** AI에게 정확히 요구하는 법을 배운다.
- **완벽함보다 완주.** 매일 1시간, 6주를 끝까지 간다.
- **결과물로 증명한다.** 학습이 아니라 실제 작동하는 앱으로 마무리한다.
- **사용자의 자리에서 본다.** 만든 게 누군가에게 정말 쓸모 있는지 끊임없이 묻는다.

## 🎯 최종 목표

**"AI가 궁금한 영업인력"이 되기.**

AI 시대를 머리로만 이해하는 사람이 아니라, **한 번이라도 직접 만들어 본 사람**이 되는 것. 그 차이가 5~7년 뒤의 시장에서 결정적이라고 믿는다.

거창한 변신이 아니라, **시대의 흐름을 안에서 이해하는 영업인력**으로 꾸준히 진화하는 것 — 그게 이 학습의 진짜 목적이다.

## 📝 1주차 회고

### 배운 것

- **Cursor + AI 협업**: 자연어로 요구하면 HTML/CSS/JS를 만들고 수정하는 흐름.
- **Git & GitHub**: init → add → commit → push, 충돌 시 pull --rebase까지.
- **웹 기초**: HTML 구조, CSS 레이아웃, JavaScript로 동작을 연결하는 방법.
- **Tailwind CSS**: CDN 방식으로 UI를 빠르게 만들고 반응형을 조정하는 감각.
- **localStorage**: 새로고침해도 데이터가 유지되는 클라이언트 저장.
- **Vercel 배포**: GitHub 연동으로 만든 페이지를 실제 URL로 공개.

### 만든 것

**백씨네 식탁** — 가족이 함께 저녁 메뉴를 고르는 웹앱 ([Live](https://vibe-coding-journey-5uzx.vercel.app/))

주요 기능:
- 가족 멤버 선택 후 메뉴에 좋아요
- 오늘의 인기 메뉴 · 좋아요 카운터
- 메뉴 추가(이모지 그리드) · 삭제
- localStorage 데이터 유지

### 1주차 한 줄 정리
